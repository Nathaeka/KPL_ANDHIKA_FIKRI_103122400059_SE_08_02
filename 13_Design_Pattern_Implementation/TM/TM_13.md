### Event Delegation dalam JavaScript
Event Delegation (Delegasi Event) adalah pola desain dalam JavaScript di mana kita menempelkan satu event listener pada elemen induk (parent), alih-alih memasang banyak event listener pada setiap elemen anak (child).

Teknik ini bekerja dengan memanfaatkan mekanisme Event Bubbling, yaitu ketika sebuah event (seperti klik) terjadi pada elemen anak, event tersebut akan merambat (menggelembung) naik ke elemen-elemen di atasnya. Dengan mendelegasikan event ke elemen induk, kita bisa memantau dan menangkap interaksi dari semua elemen anaknya hanya melalui satu titik.
```js

document.querySelector('ul').addEventListener('click', function(event) {
  if (event.target.tagName === 'LI') {
    console.log('Anda mengklik item:', event.target.innerText);
  }
  
});
```

Keuntungan Utama:

1. Performa dan Memori: Sangat efisien karena browser hanya perlu menyimpan satu fungsi listener di memori, bukan ratusan atau ribuan untuk tiap elemen.

2. Menangani Elemen Dinamis: Jika ada elemen anak baru yang ditambahkan menggunakan JavaScript di kemudian waktu, elemen tersebut akan otomatis merespon event tanpa perlu dipasangi listener baru.
