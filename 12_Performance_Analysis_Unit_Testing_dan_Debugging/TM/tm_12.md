## Tugas

Fungsi di bawah ini melakukan penjumlahan pada penghitung (counter), yang sesederhana menambahk jumlah jika kamu menekan tombol.

`hitung.js`

```js
function tambahPengitung(terkini, jumlah) {
  terkini = terkini + jumlah;
  return terkini;
}
```

`hitung.test.js`

```js
import { test } from 'node:test';
import assert from 'node:assert';
import { tambahPengitung } from './hitung.js';

test('5 tambah 3 sama dengan 8', () => {
  assert.strictEqual(tambahPengitung(5, 3), 8);
});

test('0 tambah 10 sama dengan 10', () => {
  assert.strictEqual(tambahPengitung(0, 10), 10);
});
```

Bisakah kamu tunjukkan apakah kode sudah benar atau bagian mana yang perlu diperbaiki beserta alasannya?

## Deskripsi

Logika fungsi sudah benar, namun *unit test* akan gagal karena ketiadaan kata kunci `export` pada `hitung.js`. Karena file pengujian (`hitung.test.js`) menggunakan sistem *ES Modules*, fungsi `tambahPengitung` wajib diekspor agar dapat diimpor dan dikenali. Selain itu, disarankan untuk memperbaiki *typo* penamaan fungsinya menjadi `tambahPenghitung`.
