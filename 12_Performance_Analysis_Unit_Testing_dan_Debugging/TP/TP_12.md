```js
function main() {
  const data = [
    "123",
    456,
    "hello",
    78.9,
    true,
  ];

  for (let i = 0; i < data.length; i++) {
    const result = processData(data[i]);
    console.log(`Item ${i + 1}: ${data[i]} -> ${result}`);
  }
}

function processData(data) {
  const str = data.toLowerCase();
  const num = parseInt(str);
  if (!isNaN(num) && str === String(num)) {
    return `Number: ${num * 2}`;
  }
  return `Teks: ${str} (panjangnya: ${str.length})`;
}

main();
```

## Deskripsi

terdapat dua kecacatan utama pada fungsi processData(). Pertama, terjadinya runtime error akibat pemanggilan data.toLowerCase() secara langsung pada tipe data non-string (seperti angka dan boolean) yang akan memicu error, sehingga data wajib dikonversi menjadi string terlebih dahulu. Kedua, terdapat logic error berupa hilangnya presisi desimal akibat penggunaan parseInt() yang memotong angka seperti 78.9 menjadi bilangan bulat, sehingga pendekatan yang tepat agar perhitungan tetap akurat adalah menggunakan Number() atau parseFloat().
